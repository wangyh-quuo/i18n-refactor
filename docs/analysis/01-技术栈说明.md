# 技术栈说明

> 来源：仅基于现有代码与 `package.json` / `tsconfig.json` / `rollup.config.js` / `.mocharc.json` 归纳，无脑补。

## 1. 项目技术栈与框架版本

| 类别 | 名称 | 版本（package.json） | 用途（现有代码） |
|------|------|----------------------|------------------|
| 运行时 | Node.js ESM | `"type": "module"` | CLI / 动态 import 配置 |
| 语言 | TypeScript | `^5.9.3` | 全部源码为 `.ts` |
| 包名 | `@wangyh-quuo/i18n-refactor` | `1.0.0` | npm 包 |
| 入口 | `packages/bin/i18n-cli.ts` | — | shebang `#!/usr/bin/env node` |
| 构建 | Rollup | `^4.54.0` | 输出 `dist/main.esm.js` |
| Rollup 插件 | `@rollup/plugin-typescript` | `^12.3.0` | TS 编译 |
| Rollup 插件 | `@rollup/plugin-json` | `^6.1.0` | 导入 `package.json` |
| 本地执行 | esno | `^4.8.0` | `npm run i18n` / `scan` |
| 测试 | mocha | `^11.7.5` | `test/**/*.spec.ts` |
| 测试加载 | ts-node | `^10.9.2` | `.mocharc.json` loader |
| 模块覆盖 | esbuild → esbuild-wasm | overrides | 规避原生 esbuild |

**非前端应用**：无 Vue/React 业务页面、无状态管理库、无 HTTP 接口层。本仓库是 **AST 国际化重构 CLI 工具**。

## 2. 第三方依赖特性（以现有调用为准）

### 2.1 生产依赖

| 依赖 | 版本 | 现有用法与特性 |
|------|------|----------------|
| `@babel/parser` | `^7.28.5` | JS/TS AST；`sourceType: "module"`，plugins: `typescript`、`jsx` |
| `@babel/traverse` | `^7.28.5` | 遍历 StringLiteral / TemplateLiteral；经 `babelTraverse.ts` 做 CJS/ESM 兼容 |
| `@vue/compiler-sfc` | `^3.5.13` | `parse()` 拆分 Vue SFC 的 template / script / scriptSetup |
| `@vue/compiler-dom` | `^3.5.13` | `compile(..., { mode: "module" })` 得到 template AST；使用 `NodeTypes` 等类型 |
| `commander` | `^14.0.2` | CLI：`--scan` / `--config` / `--dry-run` |
| `fast-glob` | `^3.3.3` | 扫描 `sourceDir/**/*.{vue,js,ts,jsx,tsx}`（仅 `scan()` 路径） |
| `lodash-es` | `^4.17.22` | `merge`、`omit`（init）、`isObject`（vueParser） |
| `magic-string` | `^0.30.21` | 按 offset `overwrite`，保格式 |
| `md5` | `^2.3.0` | `keyStrategy.default === 'hash'` 时取前 8 位 |
| `xlsx` | `^0.18.5` | Excel 导出（按模块多 Sheet） |

### 2.2 开发依赖（构建/测试）

`typescript`、`rollup` 及相关插件、`mocha`、`ts-node`、`esno`、`@types/*`、`tslib`、`esbuild-wasm`。

### 2.3 关键配置默认值（`packages/config/index.ts`）

- `sourceDir`: `src`
- `output.json`: `./locales/zh.json`
- `output.excel`: `./output/i18n.xlsx`
- `languages`: `['zh_CN', 'en_US']`
- `exportExcel`: `true`
- `keyStrategy.default`: `'prefix_increment'`（另支持 `'hash'`）
- `keyStrategy.prefixRoots`: `['src/*']`
- 用户配置：向上查找 `i18n.config.js`，`import` 后取 `default`，与默认 `merge`

## 3. TypeScript 编译约束（影响写法）

`tsconfig.json` 开启：`strict`、`noUncheckedIndexedAccess`、`exactOptionalPropertyTypes`、`verbatimModuleSyntax`、`isolatedModules`、`noUnusedLocals/Parameters` 等；`module`/`target` 为 `esnext`，`moduleResolution: bundler`。

## 4. 脚本与产物

| Script | 行为 |
|--------|------|
| `npm run i18n` | `esno packages/bin/i18n-cli.ts` |
| `npm run scan` | 同上 + `--scan` |
| `npm run build` | `rollup -c` → `dist/main.esm.js` |
| `npm test` | mocha |
| `bin.i18n-refactor` | 指向 `dist/main.esm.js` |

`.gitignore` 忽略：`node_modules`、`dist`、`locales`、`output`、lock 文件等。  
`.npmignore` 发布时忽略：`packages/`、`test/`、`rollup.config.js` 等（发布物依赖 `dist`）。
