# 数据流说明书

> 来源：`run` / `init` / parser / replacer / generator / scanner 现有调用链，无脑补新链路。

## 1. 入口与模式分支

```
用户命令
  npm run i18n | npm run scan | npx i18n-refactor
       │
       ▼
packages/bin/i18n-cli.ts  (commander)
  options: --scan | --config | --dry-run
       │
       ▼
core/run.ts → run(options)
```

## 2. 初始化数据流

```
run(options)
  ├─ initOptions(options)
  │    └─ context.configPath = resolve(config)
  │    └─ context.config = merge(默认, omit(options,'config'))
  │
  └─ initContext()
       ├─ findProjectConfig(targetPath)  // 向上找 i18n.config.js
       ├─ loadProjectConfig → import(fileURL).default
       ├─ context.config = merge(context.config, userConfig)
       ├─ context.existingJson = getExistingJson(output.json)
       ├─ context.lastIds = getLastKeyId(existingJson)
       └─ context.existingKeys = initExistingKeys(existingJson)
```

**全局可变状态（`context`）字段：**

| 字段 | 含义 | 谁写入 | 谁读取 |
|------|------|--------|--------|
| `config` | 合并后配置 | init | 几乎全部 |
| `configPath` | CLI 指定配置路径 | initOptions | initContext |
| `existingJson` | 磁盘已有 zh.json | initContext | （初始化后主要间接通过 existingKeys） |
| `lastIds` | 各 prefix 最大 key_N | init + getKeyByText | getKeyByText |
| `existingKeys` | 中文文案 → 完整 key | init + getKeyByText | getKeyByText |
| `zhMap` | 本次新增 key → 中文 | getKeyByText | writeJsonToFile |
| `notReplaceFiles` | 未自动替换项 | vue/script parser | run 末尾打印 |

## 3. 模式 A：仅扫描（`config.scan === true`）

```
Scanner(sourceDir).scanProject()
  └─ scanDirectoryForChinese(dir)  // 同步递归，非 fast-glob
       ├─ 目录：继续递归
       └─ 文件匹配 \.(vue|js|ts)$
            └─ scanFileForUntranslated
                 ├─ 行含中文正则
                 └─ 且行内无 $t( / t(
                      → 收集 { file, line, text }
  └─ console 输出列表或“未发现”
  └─ return（不写源文件、不走 parser）
```

## 4. 模式 B：自动替换主流程

```
Scanner.scan()
  └─ fast-glob: sourceDir/**/*.{vue,js,ts,jsx,tsx}
       │
       ▼ 对每个 filePath
parserFactory.getParser(filePath)
  ├─ .vue  → VueParser
  └─ .js/.ts/.jsx/.tsx → ScriptParser
  └─ 其他 → null（跳过）
       │
       ▼ parser.process() → replacedContent 字符串
Replacer.updateFile(filePath, replacedContent)
  └─ 若非 dryRun：fs.writeFileSync
       │
       ▼ 全部文件循环结束
打印 context.notReplaceFiles
       │
       ▼
writeJsonToFile()
  ├─ flatToNested(context.zhMap)
  ├─ mergeZhJson(nested)  // 再读盘 deepMerge
  ├─ mkdir + 写 output.json
  └─ 若 exportExcel：exportToExcelByModule
```

## 5. Vue 文件内部数据流

```
VueParser.constructor
  └─ parse SFC
       ├─ templateContent = descriptor.template.content
       └─ scriptContent = scriptSetup || script 的 content

VueParser.process()
  ├─ processTemplate(templateContent)
  │    └─ compile → walk AST
  │         ├─ TEXT / ATTRIBUTE / SIMPLE_EXPRESSION / COMPOUND / IF / ...
  │         ├─ 命中中文 → getKeyByText + 生成 replacement
  │         └─ 不支持 → notReplaceFiles
  ├─ ScriptParser.parseScript(scriptContent)  // 静态方法，不读盘
  ├─ Replacer(templateReplacements).replace(templateContent)
  ├─ Replacer(scriptReplacements).replace(scriptContent)
  └─ rawContent.replace(template原文, 新template).replace(script原文, 新script)
```

**Template 替换形态（现有）：**

| 场景 | replacement 形态 |
|------|------------------|
| 纯文本节点 | `{{ $t('key') }}` |
| 静态属性名 | 先 `:` 前缀，值 `"$t('key')"` |
| 简单表达式字符串 | `$t('key')` |
| 文本+插值复合 | `{{ $t('key', { 0: expr, ... }) }}` |
| 三元字符串分支 | `$t('key')`（偏移手工计算） |
| 数组内字符串 | `$t('key')` |

## 6. Script / 纯 JS·TS 数据流

```
ScriptParser
  ├─ 构造：读文件 → rawContent
  └─ process → parseScript(raw, path) → Replacer.replace

parseScript (Babel AST)
  ├─ StringLiteral + 中文
  │    ├─ 跳过 Import / Object key
  │    └─ replacement: t('key')
  └─ TemplateLiteral
       ├─ 含 HTML + 中文 → notReplaceFiles，return
       ├─ 有中文 + 表达式全 Identifier|MemberExpression
       │    → 整段：`${t('key', { 0: a, 1: b })}`  （注意外层仍是模板插值形态）
       └─ 否则对含中文的 quasi：`${t('key')}`
```

## 7. Key 与 JSON 数据流

```
getPagePrefix(filePath)
  └─ matchRootDir(prefixRoots) → 下一段目录名，否则 "common"

getKeyByText(text, prefix)
  ├─ trim
  ├─ 命中 existingKeys → 直接返回（不重复写入 zhMap 逻辑上仍短路）
  ├─ prefix_increment：prefix.key_{++lastIds[prefix]}
  │   或 hash：prefix.{md5前8位}
  ├─ existingKeys[text] = key
  └─ zhMap[key] = text

writeJsonToFile
  zhMap(扁平 "a.b.key_1") → flatToNested → merge 磁盘 JSON → 写回 → 可选 Excel
```

## 8. dry-run 数据流差异

```
Replacer.replace
  └─ 每次 overwrite 后 loggerDryRun（仅打印）

Replacer.updateFile
  └─ context.config.dryRun 为 true 时不写源文件

writeJsonToFile
  └─ 当前实现无 dryRun 判断 → 仍可能写 json/excel
```

## 9. 端到端链路总览（一图）

```
CLI 参数 + i18n.config.js
        ↓
   context 初始化（已有文案/key 计数）
        ↓
   ┌──── scan? ────是──→ 行级中文扫描报告 → 结束
   │否
   ↓
文件列表 → Parser(AST) → replacements[]
        ↓
 MagicString 生成新文本 →（非 dryRun）写源文件
        ↓
收集未替换警告
        ↓
zhMap → 嵌套合并 → zh.json +（可选）xlsx
```
